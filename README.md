# Résa — Frontend

React 19 + TypeScript + Vite front-end for the Résa booking platform.

## Requirements

- Node.js >= 18

## Setup

```bash
npm install
```

Create a `.env` file at the root:

```env
VITE_API_URL=https://api.resa.com/api/v1
```

## Development

```bash
npm run dev      # http://localhost:5173
npm run build
npm run lint
```

## Stack

React 19 · TypeScript · Vite · React Router v7 · TanStack Query · Axios · Tailwind CSS v4 · shadcn/ui
